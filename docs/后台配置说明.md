# 后台配置说明 · 云宿 SaaS

> 对应交付物：后台配置文档（存储/微信/多语言/菜单/租户/两级权限配置说明）。
> 适用端：PC 管理后台 `http://<host>/admin/`。
> 权限：除特别说明外，以下配置仅 **租户管理员** 可操作；平台参数仅 **平台超管** 可操作。

---

## 1. 登录与租户切换

### 1.1 平台超管

1. 打开 `/admin/`；
2. 账号 `admin`，密码 `admin123`（演示）；
3. **租户编码留空**；
4. 登录后进入「平台总览」。

### 1.2 租户用户

1. 打开 `/admin/`；
2. 输入租户编码（如 `YQ-HZ`）、账号、密码；
3. 登录后按角色进入「经营概览」，左侧菜单只显示有权限的模块。

### 1.3 平台下钻

1. 平台超管进入「租户管理」；
2. 点击目标租户「下钻」；
3. 顶部出现只读提示，可查看该租户的概览、门店、房型、订单、报表等；
4. 下钻状态仅允许 GET，新增/修改/删除按钮不展示，直接调接口也会 403；
5. 点击顶部「退出下钻」返回平台视图。

## 2. 租户管理（平台端）

路径：`平台总览` / `租户管理`。

### 2.1 开通租户

| 字段 | 说明 |
|---|---|
| 租户编码 | 唯一，建议大写字母+短横线，如 `YQ-HZ`；用于登录与公开门户路径 |
| 租户名称 | 展示名称 |
| 业态类型 | 酒店 / 民宿 / 客栈（对应 `HOTEL/HOMESTAY/HOSTEL`） |
| 联系人/电话 | 运营联系人 |
| 到期日 | 到期后自动停用（见定时任务） |
| 用户上限 / 房间上限 | 配额；新增用户/房间时校验 |
| 管理员账号/初始密码 | 不填默认 `admin/admin123`；**首次登录必须修改** |
| 备注 | 内部说明 |

### 2.2 状态与续期

- **停用**：租户状态置 `DISABLED`，该租户用户登录返回 403，数据保留。
- **启用**：恢复 `NORMAL`。
- **续费**：选择 1/3/6/12 个月，累加到期日。
- **到期治理**：每日 01:10 执行 `TenantExpiryJob`：
  - 30 天内到期：写站内预警；
  - 已过期：自动置 `DISABLED`。

### 2.3 配额

- 新增租户用户时校验 `max_users`；
- 新增房间时校验 `max_rooms`；
- 超限返回 400，提示联系平台扩容。

## 3. 用户与角色（租户端）

路径：`用户与角色`（仅租户管理员）。

### 3.1 新增用户

| 字段 | 说明 |
|---|---|
| 账号 | 租户内唯一，创建后不可改 |
| 姓名 | 展示名 |
| 初始密码 | 至少 6 位；用户首次登录后自行修改 |
| 手机号 | 联系/审计 |
| 角色 | 租户管理员/店长/前台/保洁/财务/OTA 运营 |
| 所属门店 | 可选；用于门店范围展示 |
| 状态 | 启用/停用 |

### 3.2 角色权限

| 角色 | 适用岗位 | 可见模块 |
|---|---|---|
| `TENANT_ADMIN` | 租户管理员 | 全部 |
| `STORE_MANAGER` | 店长/值班经理 | 概览、主数据、订单、前台、房务、财务、会员、报表 |
| `FRONT_DESK` | 前台/客房管家 | 概览、主数据、订单、前台、房务、会员、报表 |
| `HOUSEKEEPING` | 保洁/客房服务 | 概览、主数据、房务、报表 |
| `FINANCE` | 财务/收银 | 概览、主数据、财务、报表 |
| `OTA_OPERATOR` | OTA 运营 | 概览、主数据、订单、会员、渠道/餐饮、报表 |

> 角色为系统内置编码；当前未提供自定义角色权限编辑器。新增角色需开发扩展 `AccessInterceptor` 与前端矩阵。

### 3.3 重置密码与停用

- 「重置密码」由管理员设置新密码；
- 「删除」为逻辑删除，不可删除当前登录账号；
- 用户可在右上角头像菜单「修改密码」自助改密。

## 4. 系统配置（租户端）

路径：`系统配置`，共 6 个 Tab。

### 4.1 基础配置

| 字段 | 说明 |
|---|---|
| 租户名称 | 门户/后台展示 |
| 宣传标语 | 门户首页副标题 |
| 客服电话 | 门户展示 |
| 默认门店 | 下单默认门店 |
| Logo 地址 | 可上传后填 URL |
| 站内通知 | 开关 |
| 微信支付 | 开关（演示环境仅记录） |

保存后写入 `sys_tenant_config`，公开门户与后台读取同一份数据。

> 下方「平台参数」为只读：租户到期策略、免费取消时长、到店付保留时长、押金默认方式、实名报送开关等由平台统一维护。

### 4.2 多语言

- 语言列表来自 `sys_language`（默认 `zh-CN`、`en`）；
- 按语言筛选词条；
- 新增/编辑词条：`msgKey`（如 `booking.title`）+ 译文；
- H5 门户通过 `GET /api/public/{tenantCode}/i18n?lang=en` 获取；
- 删除词条仅影响后续读取，前端有默认文案兜底。

### 4.3 菜单配置

- 支持 `ADMIN`（管理端）、`MINI`（小程序）、`H5`（H5 门户）；
- 字段：编码、名称、所属端、路径、图标、父级编码、排序、状态；
- 排序值越小越靠前；
- H5 底部导航读取 `GET /api/public/{tenantCode}/menus?platform=H5`；
- 小程序/管理端当前使用本地配置，后台菜单数据已落库，**尚未做到所有端实时热更新**（见验收报告限制）。

### 4.4 字典扩展

- 左侧筛选全局字典类型；
- 全局标准字典只读；
- 租户可新增扩展项（类型/编码/名称/排序），写入 `sys_tenant_dict`；
- 删除仅允许删除租户扩展项。

### 4.5 文件存储

| 驱动 | 字段 | 说明 |
|---|---|---|
| 本地存储 `LOCAL` | 存储目录（展示用） | 实际目录由后端 `UPLOAD_DIR` 控制，需保证进程可写 |
| MinIO `MINIO` | Endpoint、Bucket、AccessKey、SecretKey、公开地址 | 连接测试通过后保存；AK/SK AES 加密；公开地址用于拼接文件 URL |

操作顺序：

1. 选择驱动；
2. 填写参数；
3. 点击「连接测试」；
4. 测试通过后点击「保存配置」；
5. 上传测试文件，确认返回 URL 可访问。

> 当前已实现本地与 MinIO；OSS/COS/S3 可通过 MinIO 兼容网关或后续适配。`publicUrl` 与后端 `domain` 字段兼容处理见代码 `StorageService`。

### 4.6 微信与通知

**微信配置**：

| 应用类型 | 字段 |
|---|---|
| `MINI` 小程序 | AppId、AppSecret、Token、AES Key、业务域名、启用 |
| `OFFICIAL` 公众号 | AppId、AppSecret、Token、AES Key、业务域名、启用 |

- 密钥 AES 加密存储，列表仅显示掩码；
- 编辑时留空或保留 `******` 表示不修改；
- 保存后实时生效（读取配置时解密）；
- 修改写审计。

**消息模板**：

| 字段 | 说明 |
|---|---|
| 业务类型 | 如 `BOOKING_CONFIRM`、`CHECKIN_REMIND`、`CHECKOUT_REMIND`、`MEMBER_UPGRADE` |
| 渠道 | 站内/公众号/小程序/短信 |
| 模板 ID | 微信模板 ID（真实下发时使用） |
| 标题/内容 | 站内消息与兜底文案 |
| 启用 | 开关 |

**站内消息**：展示最近 100 条，可标记已读；预订/入住/退房等节点自动写入。

> 真实公众号模板消息、小程序订阅消息、短信发送尚未接入；当前站内消息可用，模板配置仅落库。

## 5. 平台参数（平台端）

路径：平台登录后「系统配置 → 基础配置 → 平台参数（只读）」；平台写接口为 `PUT /api/platform/params`。

| 参数键 | 默认 | 作用 |
|---|---|---|
| `tenant_expire_policy` | `AUTO_DISABLE` | 到期策略 |
| `free_cancel_hours` | `24` | 免费取消默认时长 |
| `arrival_hold_hours` | `6` | 到店付保留时长 |
| `deposit_default_type` | `WECHAT` | 押金默认方式 |
| `police_report_enabled` | `true` | 实名报送开关（演示影响模拟报送状态） |

> 平台参数当前主要用于展示与部分业务读取；修改后无需重启。生产可按需扩展参数表与缓存。

## 7. 审计日志

- 租户：`审计日志` 页面，按模块/关键字分页查询；
- 平台：`平台审计`，可按租户筛选；
- 记录范围：所有写操作、失败请求、403、跨租户访问；
- 建议每月导出/归档，保留 ≥6 个月。

## 8. 配置变更与生效

| 配置 | 生效方式 |
|---|---|
| 租户基础配置 | 保存即生效（读取数据库） |
| 多语言词条 | 保存即生效（门户下次请求） |
| 菜单 | 保存即生效（读取数据库的端） |
| 字典扩展 | 保存即生效 |
| 存储配置 | 保存即生效（下次上传） |
| 微信配置 | 保存即生效（真实发送需外部联调） |
| 平台参数 | 保存即生效（部分业务读取） |
| 用户/角色 | 保存即生效（下次登录/请求） |

> 修改微信/存储密钥前请确认已备份；密钥掩码占位符 `******` 不会被覆盖。

## 9. 常见问题

**Q：登录提示“租户已停用/已到期”？**
A：平台端检查租户状态与到期日，续期或启用后重试。

**Q：新增用户提示配额不足？**
A：平台端提高该租户「用户上限」，保存后重试。

**Q：新增房间提示配额不足？**
A：提高「房间上限」；或清理无用房间（逻辑删除后仍计入？当前按未删除统计）。

**Q：上传失败？**
A：检查 `UPLOAD_DIR` 权限、磁盘空间、Nginx `client_max_body_size`、后端 20MB 限制。

**Q：MinIO 连接测试失败？**
A：检查 Endpoint 是否可从后端访问、Bucket 是否存在、AK/SK 是否正确、网络/防火墙。

**Q：修改了 JWT_SECRET 后旧数据无法解密？**
A：加密密钥由 JWT_SECRET 派生，变更会导致历史密文不可读；生产变更前先迁移或固定独立加密密钥。

**Q：平台下钻为什么不能改数据？**
A：设计为只读，避免平台误改租户业务数据；如需修改，请使用租户管理员账号。
