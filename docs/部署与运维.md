# 部署与运维 · 云宿 SaaS

> 对应任务：T74；部署形态：**Nginx 反向代理 + 宝塔/裸机 systemd 直接部署**（生产首选）。
> Dockerfile 仅为可选辅助交付，本次**不构建镜像**；容器不是主方案。
> 示例项目路径：`/home/ai/52hotel.xiegongzhu.com`，请按实际路径替换。

---

## 1. 部署架构与端口

| 组件 | 端口 | 对外 | 说明 |
|---|---|---|---|
| Nginx | 80/443 | 是 | TLS、静态资源、`/api`、`/uploads` 反向代理 |
| 后端 hotel-saas | 8080（演示 19090） | 否 | Spring Boot，仅监听回环/内网 |
| MySQL 8 | 3306 | 否 | 业务库 `hotel_saas` |
| Redis | 6379 | 否 | 缓存/限流/防重/编号锁 |
| 本地文件 | `UPLOAD_DIR` | 经 Nginx | 默认 `./data/uploads` |

```text
用户 → Nginx :443 → /            portal-web/dist
                  → /admin/      admin-web/dist
                  → /api/        127.0.0.1:8080
                  → /uploads/    127.0.0.1:8080
```

## 2. 环境准备

### 2.1 系统要求

- Linux（CentOS 7+/Ubuntu 20.04+）或宝塔面板
- JDK 17+（推荐 Temurin/OpenJDK 17）
- MySQL 8.0
- Redis 6/7
- Node.js 18+（仅构建前端时需要）
- Maven 3.8+（仅构建后端时需要）
- Nginx 1.20+

### 2.2 目录规划

```text
/opt/hotel-saas/                 # 应用目录
├── backend/hotel-saas.jar       # 后端 jar
├── admin/                       # 后台静态资源
├── portal/                      # H5 静态资源
├── data/uploads/                # 上传文件
├── logs/                        # 应用日志
└── .env                         # 环境变量（chmod 600）
```

### 2.3 创建数据库与账号

```sql
CREATE DATABASE hotel_saas DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'hotel'@'127.0.0.1' IDENTIFIED BY '请替换为强密码';
GRANT ALL PRIVILEGES ON hotel_saas.* TO 'hotel'@'127.0.0.1';
FLUSH PRIVILEGES;
```

```bash
mysql -h127.0.0.1 -uhotel -p hotel_saas < sql/init.sql
```

> `sql/init.sql` 仅建表、幂等；演示数据由 `SEED_DEMO` 控制。生产务必设置 `SEED_DEMO=false`。

## 4. 后端 systemd 托管

### 4.1 创建运行用户（推荐）

```bash
useradd -r -s /sbin/nologin hotel
chown -R hotel:hotel /opt/hotel-saas
chmod 600 /opt/hotel-saas/.env
```

### 4.2 环境变量文件

`/opt/hotel-saas/.env`：

```bash
SERVER_PORT=8080
DB_URL=jdbc:mysql://127.0.0.1:3306/hotel_saas?useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Shanghai&rewriteBatchedStatements=true
DB_USERNAME=hotel
DB_PASSWORD=请替换为强密码
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=请替换为Redis密码
JWT_SECRET=请替换为至少32字节随机串
JWT_EXPIRE_HOURS=12
UPLOAD_DIR=/opt/hotel-saas/data/uploads
PUBLIC_BASE_URL=https://your-domain.com
SEED_DEMO=false
TZ=Asia/Shanghai
```

生成随机密钥：

```bash
openssl rand -base64 48
```

### 4.3 systemd 单元

`/etc/systemd/system/hotel-saas.service`：

```ini
[Unit]
Description=Hotel SaaS Backend
After=network.target mysql.service redis.service
Wants=mysql.service redis.service

[Service]
Type=simple
User=hotel
Group=hotel
WorkingDirectory=/opt/hotel-saas
EnvironmentFile=/opt/hotel-saas/.env
ExecStart=/usr/lib/jvm/jdk-17/bin/java \
  -Xms512m -Xmx1024m \
  -Duser.timezone=Asia/Shanghai \
  -Dfile.encoding=UTF-8 \
  -jar /opt/hotel-saas/backend.jar
SuccessExitStatus=143
Restart=always
RestartSec=5
LimitNOFILE=65535
StandardOutput=append:/opt/hotel-saas/logs/backend.log
StandardError=append:/opt/hotel-saas/logs/backend.error.log

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now hotel-saas
systemctl status hotel-saas
curl -fsS http://127.0.0.1:8080/api/health
```

> 若使用宝塔：在「网站 → Java 项目」中添加项目，启动命令同上，环境变量在面板中配置；或仍用 systemd 托管，宝塔仅做 Nginx/SSL。

## 5. Nginx 配置

### 5.1 站点配置

复制 `nginx/hotel-saas.conf` 到 `/etc/nginx/conf.d/hotel-saas.conf`，替换：

- `__PROJECT_ROOT__` → 实际项目根路径（例如 `/home/ai/52hotel.xiegongzhu.com`）；
- `proxy_pass http://127.0.0.1:8080` → 实际后端端口（演示环境为 19090）；
- `access_log/error_log` → 确保目录存在：标准 Nginx 为 `/var/log/nginx`，宝塔通常为 `/www/wwwlogs`，不存在时先 `mkdir -p` 或改路径，否则 `nginx -t` 会报 open() failed。

> 已验证：替换路径后 `nginx -t` 通过；以 18991 端口实际反代后，门户 `/`、后台 `/admin/`、后台深链、`/api/health`、静态资源均返回 200。

```nginx
server {
    listen 80;
    server_name your-domain.com;
    client_max_body_size 60m;
    charset utf-8;

    location / {
        root /home/ai/52hotel.xiegongzhu.com/portal-web/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    location ^~ /admin/ {
        alias /home/ai/52hotel.xiegongzhu.com/admin-web/dist/;
        index index.html;
        try_files $uri $uri/ /admin/index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:19090/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 10s;
        proxy_read_timeout 60s;
    }

    location /uploads/ {
        proxy_pass http://127.0.0.1:19090/uploads/;
        proxy_set_header Host $host;
        expires 7d;
    }
}
```

校验并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

### 5.2 HTTPS

使用宝塔「SSL」或 certbot：

```bash
certbot --nginx -d your-domain.com
```

或手动配置 443：

```nginx
server {
    listen 443 ssl http2;
    server_name your-domain.com;
    ssl_certificate     /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    # 其余 location 与 80 端口一致
}
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}
```

上线后将 `PUBLIC_BASE_URL` 改为 `https://your-domain.com`，确保上传文件 URL 正确；微信合法域名必须为 HTTPS。

### 5.3 安全响应头

配置已包含：

```nginx
add_header X-Content-Type-Options nosniff always;
add_header X-Frame-Options SAMEORIGIN always;
add_header Referrer-Policy strict-origin-when-cross-origin always;
```

如启用 HSTS，确认全站 HTTPS 后再加 `Strict-Transport-Security`。

## 6. 一键启动脚本（开发/验收）

```bash
cp .env.example .env
./start.sh          # 检查环境 → 建表 → 构建 → 启动后端/后台/H5
./stop.sh           # 停止脚本拉起的进程
```

脚本特性：

- 自动寻找 JDK 17+（系统默认 Java 8 时会主动切换）；
- 端口被占用时按 `PORT_FALLBACK=true` 自动顺延；
- `BUILD_BACKEND=auto` 时仅源码比 jar 新才构建；
- 缺少 `node_modules` 时自动 `npm install`；
- Redis 不可用时默认失败，`ALLOW_DEGRADED=true` 可降级；
- 运行时文件：`.runtime/*.pid`、`.runtime/*.port`、`.runtime/urls.env`；
- 日志：`logs/backend.log`、`logs/backend-build.log`、`logs/admin.log`、`logs/portal.log`。

> 一键脚本用于开发/验收，不替代生产 systemd；生产请使用第 4 节方式托管。

## 7. 日志

| 日志 | 位置 | 用途 |
|---|---|---|
| 后端应用 | `/opt/hotel-saas/logs/backend.log` | 业务/异常 |
| 后端错误 | `/opt/hotel-saas/logs/backend.error.log` | 启动失败/未捕获异常 |
| Nginx 访问 | `/var/log/nginx/hotel-saas.access.log` | 请求、状态码、耗时 |
| Nginx 错误 | `/var/log/nginx/hotel-saas.error.log` | 反代/静态资源错误 |
| MySQL 慢查询 | `/var/log/mysql/slow.log` | 性能排查 |

日志轮转 `/etc/logrotate.d/hotel-saas`：

```text
/opt/hotel-saas/logs/*.log {
    daily
    rotate 14
    compress
    missingok
    notifempty
    copytruncate
}
```

## 8. 备份

### 8.1 数据库

```bash
cat >/opt/hotel-saas/backup.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
source /opt/hotel-saas/.env
STAMP=$(date +%F)
mkdir -p /backup/hotel-saas
mysqldump -h127.0.0.1 -u"$DB_USERNAME" -p"$DB_PASSWORD" \
  --single-transaction --routines --triggers --default-character-set=utf8mb4 \
  "$DB_NAME" | gzip > "/backup/hotel-saas/db_${STAMP}.sql.gz"
tar czf "/backup/hotel-saas/uploads_${STAMP}.tar.gz" -C /opt/hotel-saas data/uploads
find /backup/hotel-saas -type f -mtime +7 -delete
EOF
chmod 700 /opt/hotel-saas/backup.sh
```

```cron
0 2 * * * /opt/hotel-saas/backup.sh >> /opt/hotel-saas/logs/backup.log 2>&1
```

- 每日 02:00 全量，保留 7 份；建议再同步到异地/对象存储。
- 恢复演练见《数据库设计.md》第 7 节。

### 8.2 配置与文件

- `.env` 单独加密备份（含数据库/Redis/JWT 密钥）。
- Nginx 配置、systemd 单元纳入版本管理/配置备份。
- MinIO/对象存储开启版本保护（如服务商支持）。

## 9. 监控与告警

| 项目 | 方案 |
|---|---|
| 存活 | `GET /api/health`，Nginx/宝塔/UptimeRobot 每 1 分钟探测 |
| 进程 | `systemctl status hotel-saas`；`Restart=always` 自动拉起 |
| 资源 | `top`/`htop`、`df -h`、`free -m`；宝塔监控或 Prometheus node_exporter |
| MySQL | 连接数、慢查询、磁盘；`SHOW PROCESSLIST` |
| Redis | `redis-cli -a *** INFO`、内存使用 |
| 业务 | 每日核对订单/结算/入住量；平台看板到期预警 |
| 日志告警 | 对 `ERROR`、5xx、`401/403` 突增设置关键字告警 |

建议阈值：

- 磁盘使用率 > 80% 告警；
- JVM 堆持续 > 85% 关注；
- MySQL 连接数 > 80% 告警；
- `/api/health` 连续 3 次失败告警。

## 10. 故障排查

| 现象 | 排查 | 处理 |
|---|---|---|
| 502 Bad Gateway | `systemctl status hotel-saas`、`curl 127.0.0.1:8080/api/health` | 启动后端；检查端口/Nginx `proxy_pass` |
| 前端 404（刷新后） | Nginx `try_files` | 确认 `/admin/` 使用 `alias` 且回退 `/admin/index.html` |
| 登录 401 | Token 过期、`JWT_SECRET` 变更 | 重新登录；多实例需统一密钥 |
| 登录 403 | 租户停用/到期 | 平台续期/启用；核对 `expire_time` |
| 跨租户 403 | 正常拦截 | 核对账号租户；平台下钻用 `X-Tenant-Id` 且仅 GET |
| 数据库连接失败 | 账号/端口/防火墙/`DB_URL` | 用 mysql 客户端验证；检查 Hikari 日志 |
| Redis 连接失败 | 密码/保护模式 | `redis-cli -a *** ping`；生产不建议降级 |
| 上传失败 | 目录权限/大小限制 | `chown hotel`；Nginx `client_max_body_size`；后端 20MB/60MB |
| 图片 404 | `PUBLIC_BASE_URL`/Nginx `/uploads/` | 修改环境变量并重启；确认文件存在 |
| 中文乱码 | 库/表/连接字符集 | 统一 utf8mb4；检查 JDBC `characterEncoding=utf8` |
| 定时任务未执行 | 时区/调度 | JVM `Asia/Shanghai`；查看 `TenantExpiryJob` 日志 |
| 端口占用 | `ss -ltnp \| grep 8080` | 释放端口或改 `SERVER_PORT` |
| 构建内存不足 | Maven/Node OOM | 增加内存/swap；`NODE_OPTIONS=--max-old-space-size=2048` |

## 12. Docker（可选辅助，不构建）

```bash
  -e DB_URL='jdbc:mysql://mysql:3306/hotel_saas?...' \

  -e REDIS_HOST=redis -e REDIS_PORT=6379 -e REDIS_PASSWORD='' \
  hotel-saas:1.0.0
```
