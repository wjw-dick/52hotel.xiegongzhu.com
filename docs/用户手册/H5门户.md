# H5 门户用户手册（portal-web）

> 适用地址：`http://<域名或IP>/`（开发态 `http://127.0.0.1:5174/`）
> 面向：C 端住客、未登录访客；支持手机与 PC 浏览器。
> 追溯：PRO.md §2.6 H5 portal-web；checklist §十八（H5）、§五（订单查询）。

---

## 1. 首页

打开门户后可见：

- 品牌主视觉与宣传语；
- 快速查询：入住/离店日期 →「查询房态」；
- 房型甄选：房型图片、名称、参考价、可住人数；
- 门店展示：门店名称、城市、地址、电话、简介；
- 服务特色/公告；
- 顶部导航：首页 / 预订 / 订单查询 / 会员中心；
- 语言切换：中文 / English（词条级）。

### 1.1 查询房态

1. 选择入住日期、离店日期；
2. 点击「查询房态」；
3. 进入预订页，选择门店与房型，系统实时计算可订房量与价格。

> 日期不能早于今天，离店日期必须晚于入住日期。

---

## 2. 房型详情

从首页房型卡片或门店房型进入：

- 房型名称、门店、面积、可住人数、床型、设施；
- 图片；
- 未来 30 天房价；
- 预订须知；
- 「去预订」按钮（携带房型/日期参数）。

---

## 3. 在线预订

### 3.1 填写预订信息

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 门店 | 是 | 选择门店后房型联动 |
| 房型 | 是 | 显示起价 |
| 入住日期 | 是 | 不早于今天 |
| 离店日期 | 是 | 晚于入住日期 |
| 房间数 | 是 | 1~3 间 |
| 支付方式 | 是 | 到店支付 / 在线支付（演示） |
| 姓名 | 是 | 真实姓名 |
| 手机号 | 是 | 用于确认与订单查询 |
| 身份证号 | 是 | 入住登记与公安报送，加密存储 |
| 协议单位 | 否 | 企业协议客户 |
| 预计到店 | 否 | 时间段 |
| 备注 | 否 | 高楼层/安静/亲子等 |

右侧订单摘要实时显示：房型、门店、日期、间夜、可订房量、参考单价、预计总价。

### 3.2 提交

1. 点击「提交预订」；
2. 系统校验日期、房量、房价、实名信息；
3. 成功后显示订单号、入住/离店日期、金额；
4. 可点击「查看订单」或「返回首页」。

> 提交后房间即锁定。若需取消，请通过订单查询/会员中心取消，或联系门店。

### 3.3 支付说明

- 「到店支付」：下单后到店结算；
- 「在线支付（演示）」：当前仅记录支付方式，未接入真实微信/支付宝支付；
- 真实支付能力需上线后接入商户号与回调。

---

## 4. 订单查询

1. 顶部「订单查询」；
2. 输入订单号（如 `YQ-HZ-2026-0001`）与下单手机号；
3. 点击「查询订单」；
4. 查看订单号、门店、房型、状态、入住人、入住/离店、房间、金额、备注；
5. 可「联系门店」或「再订一间」。

> 手机号必须与下单时一致，否则返回权限错误。

---

## 5. 会员中心

### 5.1 登录（演示）

1. 进入「会员中心」；
2. 演示环境不跳转微信授权，直接填写 OpenId（如 `demo-openid-001`）、昵称、手机号；
3. 点击「微信一键登录」。

> 正式环境应通过公众号网页授权/小程序静默授权获取 OpenId/UnionID，当前为演示占位。

### 5.2 会员信息

登录后显示：

- 昵称、手机号（掩码）、会员等级、折扣；
- 可用积分、储值余额、可用优惠券；
- 等级权益说明。

### 5.3 我的订单

- 查看全部订单；
- 待确认/已确认订单可「取消订单」；
- 取消后释放房间，状态变为已取消。

### 5.4 积分 / 优惠券 / 消息

- 积分：变动值、原因、时间；
- 优惠券：名称、面额、有效期、状态；
- 消息：预订/入住/退房/会员等站内通知。

### 5.5 个人资料与改密

- 修改昵称、手机号、性别；
- 修改密码：演示环境验证码为手机号后 6 位；新密码至少 6 位。

### 5.6 退出

点击右上角「退出」清除本地登录态。

## 6. 多语言

- 顶部语言切换；
- 当前支持中文/English 词条；
- 切换后首页、预订、订单等文案随之变化；
- 房型/门店等业务内容暂为单语言，后续可扩展多语言字段。

## 7. 常见问题

**Q：查询不到房型/价格？**
A：确认租户门户已配置门店/房型且状态启用；日期是否在可售范围。

**Q：提交预订提示“暂无可用房”？**
A：所选日期房型已满，换日期/房型/门店重试。

**Q：订单查询提示无权限？**
A：订单号或手机号不匹配；请使用下单手机号。

**Q：支付后订单状态没变？**
A：当前在线支付为演示，未接真实回调；到店支付由前台入住时确认。

**Q：会员登录后看不到订单？**
A：演示登录会新建/匹配会员，历史匿名订单不会自动归属；可用订单号+手机号查询。

**Q：修改密码收不到验证码？**
A：演示环境无短信，填写手机号后 6 位即可；真实环境需接短信服务。

**Q：页面在微信内打开样式异常？**
A：建议使用最新版微信/手机浏览器；如仍异常，清理缓存或联系管理员。

## 8. 隐私与合规

- 身份证号仅用于入住登记与公安报送，后端加密存储；
- 手机号在会员信息中掩码展示；
- 提交预订即表示同意《入住须知》《隐私政策》（页面文案）；
- 真实上线需补齐隐私政策、用户协议、个人信息收集清单与撤回机制。
