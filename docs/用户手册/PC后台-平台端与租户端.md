# PC 管理后台用户手册（平台端 / 租户端）

> 适用地址：`http://<域名或IP>/admin/`（开发态 `http://127.0.0.1:5173/admin/`）
> 对应端：PC 管理后台；覆盖平台超管与租户各角色。
> 追溯：PRO.md §2.1 平台端、§2.2 租户端、§2.3 住宿业务域；checklist §二、§三、§四、§五、§八、§九、§十一、§十六、§十九。

---

## 1. 登录

1. 浏览器打开 `/admin/`；
2. 输入账号、密码；
3. **平台超管不填租户编码**；租户用户填写租户编码（如 `YQ-HZ`）；
4. 点击「登录」。

登录后：

- 平台超管默认进入「平台总览」；
- 租户用户默认进入「经营概览」，左侧菜单按角色显示。

右上角头像菜单可「修改密码」「退出登录」。

> 演示账号见 README。首次登录后请立即修改默认密码。

## 2. 平台端（system 超管）

### 2.1 平台总览

查看：

- 租户总数、正常租户数；
- 全平台房间数、在住数、入住率；
- 订单总数、今日到店；
- 会员总数、累计营收、本月营收；
- 近 7 日订单/营收趋势；
- 各租户对比（房间/入住率/订单/营收/会员/用户）；
- 30 天内到期租户预警。

### 2.2 租户管理

| 操作 | 步骤 |
|---|---|
| 开通租户 | 「租户管理」→「开通租户」→ 填写编码/名称/类型/到期日/配额/管理员账号 → 保存 |
| 编辑租户 | 行内「编辑」→ 修改名称/联系人/到期日/配额 → 保存 |
| 续费 | 行内「续费」→ 选择 1/3/6/12 个月 → 确认 |
| 停用/启用 | 行内「停用/启用」→ 二次确认；停用后该租户用户无法登录 |
| 下钻 | 行内「下钻」→ 进入只读视图；可查看概览/门店/房型/订单/报表；写操作被禁止 |
| 退出下钻 | 顶部「退出下钻」返回平台视图 |

> 租户编码创建后不可修改；编码用于登录与公开门户 URL。

### 2.3 全局字典

- 查看/新增/修改/删除平台标准字典；
- 租户只能读取标准字典并新增自己的扩展项，不能改标准；
- 建议类型见《后台配置说明.md》第 6 节。

### 2.4 平台审计

- 按租户、关键字分页查询；
- 记录平台/租户写操作、失败请求、403、跨租户访问；
- 用于追责与安全排查。

### 2.5 平台参数

平台参数由平台统一维护（租户到期策略、免费取消时长、到店付保留时长、押金默认方式、实名报送开关）。当前 UI 在租户「系统配置」中以只读表格展示；平台可通过接口批量保存。

## 3. 租户端

### 3.1 经营概览

展示：

- 房间总数、在住、入住率；
- 今日到店/离店/在住/脏房/待处理任务；
- 今日营收、本月营收、会员数；
- 近 7 日营收/订单趋势；
- 房态分布、今日到店列表、租户到期日。

用途：店长/管理员每日晨会、前台交接班前快速掌握经营状态。

### 3.2 门店与房源

Tab：门店管理 / OTA 渠道 / 餐饮挂账。

**门店管理**

- 新增/编辑门店：编码、名称、城市、电话、地址、简介、状态；
- 查看经营快照：房间/入住/订单/营收；
- 删除门店前需确保无房间/订单（服务层校验）。

**OTA 渠道**（演示）

- 新增渠道（名称、编码、是否同步库存）；
- 点击「同步」更新最近同步时间；真实渠道对接未接入。

**餐饮挂账**

- 录入餐饮消费：房间、客人、消费项目、金额；
- 对已产生订单点击「挂账到房」，结算方式置为 `ROOM`；
- 与住宿统一结算的能力已具备数据基础，收银台未做合并账单向导。

### 3.3 房型 / 房间 / 房价

**房型管理**

- 新增/编辑：所属门店、名称、编码、门市价、面积、可住人数、床型、设施、介绍、状态；
- 删除前检查是否被房间/订单引用。

**房间管理**

- 新增/编辑：门店、房型、楼层、房间号、房态、门锁编号、备注；
- 支持按门店/房型/房态/关键字筛选；
- 支持 CSV 导出/导入（模板字段与列表一致）；
- 房间数受租户配额限制；
- 房态：空房、预订、在住、脏房、维修、关闭；
- 点击房态可变更并写日志。

**房价日历**

- 选择房型与月份；
- 查看每日 BAR/渠道/协议价；
- 批量改价：选择日期区间（最长 6 个月）、价格类型、价格；
- 每次改价写入改价记录，可追溯操作人与原价/新价。

### 3.4 预订管理

**列表**

- 按关键字（订单号/入住人/手机号）、状态、来源、门店、日期筛选；
- 显示订单号、入住人、手机号、门店、房型、房间、入住/离店、金额、状态、来源；
- 分页浏览。

**新建订单**

1. 点击「新建订单」；
2. 选择门店、房型、入住/离店日期；
3. 点击「查询可用房」，系统返回可用房间与价格；
4. 可指定房间；
5. 填写入住人、手机号、证件号、来源、支付方式、协议单位、优惠、备注；
6. 保存后生成订单号并锁定房间。

**订单操作**

| 操作 | 说明 |
|---|---|
| 详情 | 查看订单、住客、入住、结算、状态日志 |
| 取消 | 仅 PENDING/CONFIRMED/WAITLIST 可取消；释放房间并记录原因 |
| 入住 | 跳转/弹出入住登记（前台角色） |
| 退房 | 在住订单可结算退房 |
| 换房 | 选择新房间，原房释放、新房占用，写换房记录 |
| 续住 | 修改离店日期并重新计价 |
| 补押金 | 收取/退还押金，写押金流水 |

### 3.5 前台接待

见《前台与客房管家端.md》，此处不重复。

### 3.6 房务保洁

见《保洁与客房服务端.md》。

### 3.7 收银财务

Tab：结算单 / 收银流水 / 押金流水 / 应收挂账 / 交接班。

- **结算单**：按日期筛选，查看房费、其他费用、优惠、押金扣减、实收、支付方式、收银员；
- **收银流水**：关联订单、业务类型、金额、支付方式、操作人、时间；
- **押金流水**：客人、收取/退还、金额、支付方式、操作人；
- **应收挂账**：新增协议/企业客户，查看余额；可挂账/核销并查看流水；
- **交接班**：开班（备用金）、交班；同一门店已有 OPEN 班次时不可重复开班。

### 3.8 会员营销

- 会员列表：姓名、手机号、等级、积分、储值、累计消费、标签、入会时间；
- 新增/编辑会员：姓名、手机号、性别、等级、标签、状态；
- 会员详情：订单、积分流水、优惠券；
- 积分调整：填写变动值与原因，写流水；
- 发券：券名、面额、有效期；
- 会员等级：查看等级门槛/折扣/权益；「重算等级」按累计消费刷新。

### 3.9 报表中心

- 选择日期区间；
- 查看营收、订单、间夜、入住率、ADR、RevPAR、会员数；
- 来源分布、房型统计、门店统计、每日趋势；
- 点击「导出 CSV」下载（Excel 可直接打开）。

### 3.10 系统配置

见《后台配置说明.md》，包含基础配置、多语言、菜单、字典扩展、文件存储、微信与通知。

### 3.11 用户与角色

- 新增用户：账号、姓名、初始密码、手机号、角色、所属门店、状态；
- 编辑用户：姓名、手机号、角色、门店、状态；
- 重置密码；
- 删除用户（不可删除自己）；
- 查看系统内置角色与权限范围。

### 3.12 审计日志

- 按模块、关键字筛选；
- 查看操作人、动作、目标、IP、详情、时间；
- 仅租户管理员可见。

## 5. 常见问题

**Q：登录后没有左侧菜单？**
A：确认账号角色；保洁/财务只显示授权模块。

**Q：新建订单查不到可用房？**
A：检查日期、房型、房态；已有冲突订单或房间被关闭/维修时不可用。

**Q：入住时提示证件无效？**
A：证件号至少 15 位；实名登记为强制要求。

**Q：退房金额与预期不一致？**
A：系统按房价日历逐夜计价，再减押金抵扣/优惠、加其他费用；检查房价日历是否维护。

**Q：房间数/用户数无法新增？**
A：租户配额已满，联系平台提高上限。

**Q：导出 CSV 中文乱码？**
A：文件带 UTF-8 BOM，建议用 Excel 直接打开；WPS 如仍乱码请选择 UTF-8 导入。

**Q：平台下钻看不到写按钮？**
A：设计为只读，防止平台误改租户数据。

## 6. 操作建议

- 每日开店前：检查今日到店/离店、脏房、待处理任务；
- 每日闭店前：核对收银流水、押金、交接班；
- 每周：检查房价日历、渠道同步、会员等级；
- 每月：导出报表、备份数据、审查审计日志中的异常 403/429。
