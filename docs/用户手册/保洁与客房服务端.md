# 保洁 / 客房服务端用户手册

> 入口：PC 管理后台 `/admin/` →「房务保洁」
> 适用角色：`HOUSEKEEPING`（保洁/客房服务）、`STORE_MANAGER`、`TENANT_ADMIN`
> 追溯：PRO.md §2.9 业务一线端（保洁/客房服务）、§2.3 住中房务；checklist §七、§十八。

---

## 1. 登录与首页

1. 打开 `/admin/`；
2. 输入租户编码、保洁账号、密码；
3. 左侧进入「房务保洁」。

顶部四张卡片：

| 卡片 | 含义 |
|---|---|
| 脏房 | 当前待清扫/待检查房间数 |
| 待办任务 | 未完成的清扫任务数（含续住、退房、保养） |
| 维修中 | 当前维修工单数 |
| 待处理客诉 | 未办结客诉数；脚注显示空房数 |

---

## 2. 清扫任务

### 2.1 查看任务

- 按状态筛选：待处理 / 处理中 / 已完成；
- 列表显示房间、房型、门店、任务类型、状态、负责人、备注、创建时间；
- 任务类型：
  - 退房清扫（`CHECKOUT`）：退房后自动生成；
  - 在住续扫（`CONTINUE`）；
  - 空房保养（`MAINTAIN`）。

### 2.2 处理任务

1. 待处理任务点击「开始」→ 状态变为处理中；
2. 完成清扫后点击「完成清扫」；
3. 系统自动：
   - 任务状态置「已完成」，记录完成时间；
   - 房间状态置「空房」；
   - 写房态变更日志。

> 若房间仍有客人/维修，请勿点击完成；可先备注联系前台。

### 2.3 新建任务

1. 点击「新建任务」；
2. 选择房间（显示房号/房型/当前房态）；
3. 选择任务类型；
4. 填写负责人、备注；
5. 保存。

创建任务后房间会被置为「脏房」，请及时处理。

---

## 3. 报修工单

### 3.1 报修登记

1. 点击「报修登记」；
2. 选择房间；
3. 填写报修内容（如空调不制冷、马桶漏水）；
4. 可填写图片 URL/附件说明（当前为文本字段）；
5. 提交。

系统会将房间状态置为「维修」，并生成工单。

### 3.2 工单流转

状态：`已报修 → 已派工 → 维修中 → 待验收 → 已完成`。

- 在报修列表点击操作按钮推进状态；
- 可填写维修人；
- 维修完成后，房间恢复为空房（以系统实际逻辑为准）；
- 无法修复时请联系前台关闭房间。

---

## 4. 布草管理

1. 进入「布草管理」；
2. 点击「收发登记」；
3. 选择类型：
   - 领用（`TAKE`）；
   - 送洗（`WASH`）；
   - 归还（`BACK`）；
4. 填写布草名称、数量、操作人；
5. 保存。

列表可按时间查看历史，用于盘点与对账。

> 当前未做库存结余自动计算与超期提醒；请按班次人工核对。

---

## 5. 客诉处理

1. 进入「客诉处理」；
2. 点击「登记客诉」：
   - 房间号；
   - 客人称呼；
   - 客诉内容；
3. 保存后状态为「待处理」；
4. 点击「受理」→ 处理中；
5. 处理完成点击「办结」，填写处理人。

> 重大客诉/安全隐患请立即上报店长，并在备注中记录。

---

## 6. 房态上报与异常

- 清扫完成即完成「脏房 → 空房」上报；
- 发现物品损坏/遗失：
  1. 在报修工单登记；
  2. 备注房间号与物品；
  3. 通知前台/店长；
- 发现客人遗留物品：交前台登记，勿自行处理；
- 发现可疑人员/安全隐患：立即上报，必要时报警。

## 7. 常见问题

**Q：看不到“房务保洁”菜单？**
A：账号角色不是保洁/店长/管理员；联系管理员调整角色。

**Q：完成任务后房间还是脏房？**
A：确认点击的是「完成清扫」而非仅「开始」；刷新页面；若仍异常，联系管理员查看房态日志。

**Q：报修后房间为什么不能卖？**
A：报修自动置「维修」；维修完成后需恢复房态，或由前台手动改为空房。

**Q：布草数量和实际不一致？**
A：检查是否漏登记领用/送洗/归还；当前无自动库存，需人工盘点。

**Q：客人投诉噪音/服务，保洁能处理吗？**
A：登记客诉并转前台/店长；保洁不直接承诺赔付。

**Q：手机能操作吗？**
A：后台为响应式页面，可用手机浏览器访问；建议横屏或使用平板获得更好体验。当前未提供独立保洁 App。
