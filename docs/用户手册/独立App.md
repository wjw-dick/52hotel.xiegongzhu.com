## 2. 本地运行

### 2.1 环境要求

- Flutter 3.19+（Dart 3.3+）
- Android Studio / Xcode（对应平台工具链）
- 真机或模拟器
- 后端可访问（演示 `http://127.0.0.1:19090/api`）

### 2.2 生成平台工程并拉依赖

仓库只保留 `lib/` 与 `pubspec.yaml`，首次运行需生成 `android/`、`ios/` 等平台目录：

```bash
cd app
flutter create .
flutter pub get
```

> `flutter create .` 会补全平台工程，不会覆盖已有 `lib/`；执行前建议提交/备份。

### 2.3 配置后端地址

编辑 `app/lib/config.dart`，或运行时用 `--dart-define` 覆盖：

```bash
# Android 模拟器访问宿主机
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:19090/api --dart-define=TENANT_CODE=YQ-HZ

# iOS 模拟器
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:19090/api --dart-define=TENANT_CODE=YQ-HZ

# 真机（同一局域网）
flutter run --dart-define=API_BASE_URL=http://192.168.1.20:19090/api --dart-define=TENANT_CODE=YQ-HZ
```

默认值：

```dart
baseUrl = 'http://127.0.0.1:8080/api'
tenantCode = 'YQ-HZ'
```

> 生产环境必须改为 HTTPS 域名；Android 9+ 默认禁止明文 HTTP，调试需配置 `networkSecurityConfig` 或使用 HTTPS。

### 2.4 构建

```bash
flutter build apk --release \
  --dart-define=API_BASE_URL=https://your-domain.com/api \
  --dart-define=TENANT_CODE=YQ-HZ

flutter build ios --release \
  --dart-define=API_BASE_URL=https://your-domain.com/api \
  --dart-define=TENANT_CODE=YQ-HZ
```

iOS 需在 Xcode 配置签名与证书；上架需 Apple Developer 账号与隐私清单。

## 3. 首页

1. 顶部品牌区显示租户名称、宣传语；
2. 快速预订卡片：点击日期范围 → 选择入住/离店；
3. 「查询房态并预订」进入房型列表；
4. 公告条展示租户公告；
5. 房型卡片：封面、名称、面积、人数、床型、简介、起价；
6. 门店卡片：名称、城市、地址、简介、电话；
7. 底部导航：首页 / 订单 / 我的。

支持下拉刷新与错误重试；接口异常时显示错误信息与「重新加载」。

## 4. 房型详情与预订

### 4.1 房型详情

- 房型信息、图片、设施、可住人数；
- 未来房价日历；
- 选择日期后查询可订房量；
- 显示晚数、参考总价；
- 底部「立即预订」。

### 4.2 填写预订

| 字段 | 必填 | 说明 |
|---|---|---|
| 姓名 | 是 | 真实姓名 |
| 手机号 | 是 | 11 位 |
| 身份证号 | 是 | 至少 15 位，后端加密 |
| 协议单位 | 否 | 企业客户 |
| 备注 | 否 | 特殊需求 |

提交前校验姓名/手机号/证件；成功后展示订单号与入住提示，可返回首页。

> 当前固定 `payType=ARRIVAL`（到店付），未接入 Apple Pay/微信支付/支付宝。

## 5. 我的订单

- 未登录：提示前往「我的」登录；
- 已登录：展示本人订单（订单号、状态、日期、晚数、金额）；
- 待确认/已确认可取消，取消前二次确认；
- 下拉刷新；
- 修改入住信息需联系门店前台。

## 6. 会员中心

### 6.1 演示登录

1. 进入「我的」；
2. 填写 OpenId（默认 `demo-app-001`）、昵称、手机号；
3. 点击微信登录；
4. 后端 `/auth/wechat-login` 返回 JWT，使用 `shared_preferences` 持久化。

> 这是演示登录，不是微信开放平台移动应用授权。正式上线需接入微信 OpenSDK，获取 code 后由后端换 UnionID，并与小程序/公众号绑定同一开放平台账号。

### 6.2 会员信息

- 昵称、手机号、等级、权益；
- 可用积分、优惠券数量；
- 可修改姓名/手机号并保存（`PUT /member/profile`）。

### 6.3 四个 Tab

| Tab | 内容 |
|---|---|
| 订单 | 本人订单，可取消 |
| 积分 | 变动值、原因、时间 |
| 优惠券 | 名称、面额、有效期 |
| 消息 | 站内通知（预订/入住/退房/会员等） |

### 6.4 退出

清除本地 token 与页面状态。

## 9. 常见问题

**Q：`flutter run` 报找不到 android/ios 目录？**
A：先执行 `cd app && flutter create .`。

**Q：Android 模拟器请求失败？**
A：宿主机地址用 `10.0.2.2`，不是 `127.0.0.1`；确认后端监听 `0.0.0.0` 且防火墙放行。

**Q：iOS 真机无法访问 HTTP？**
A：ATS 默认禁止明文，调试可临时配置例外，生产必须 HTTPS。

**Q：登录提示失败？**
A：确认租户编码、后端 `/auth/wechat-login` 可用；演示 OpenId 不能为空。

**Q：订单列表为空？**
A：演示登录新建/匹配会员，匿名订单不会自动归属；用小程序/H5 的订单号+手机号查询。

**Q：能改密码/注销吗？**
A：当前骨架未提供页面；接口侧已有 `/member/password`，可按现有 UI 模式补充。

**Q：为什么交付说明写“未编译”？**
A：当前环境没有 Flutter SDK，无法真实执行构建；文档如实标注，避免误判为已验证。
