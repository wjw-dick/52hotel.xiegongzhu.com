# 前台 / 客房管家端用户手册

> 入口：PC 管理后台 `/admin/` →「前台接待」「预订管理」「收银财务」
> 适用角色：`FRONT_DESK`（前台）、`STORE_MANAGER`（店长/值班经理）、`TENANT_ADMIN`
> 追溯：PRO.md §2.8 业务一线端（前台/客房管家）、§2.3 预订/入住/结算；checklist §五、§六、§八、§十八。

---

## 1. 登录与工作台

1. 打开 `/admin/`，输入租户编码、前台账号、密码；
2. 默认进入「经营概览」；
3. 左侧进入「前台接待」。

「前台接待」顶部四张卡片：

| 卡片 | 含义 |
|---|---|
| 今日预抵 | 今日应到店、待办理入住的订单数 |
| 今日预离 | 今日应离店、待退房结算的订单数 |
| 在住 | 当前在住房间数；脚注显示空房/脏房 |
| 今日日期 | 当班日期 |

---

## 2. 今日接待

### 2.1 预抵订单

1. 在「今日接待」查看「预抵订单」；
2. 核对订单号、入住人、手机号、房型、房间、金额；
3. 点击「办理入住」；
4. 在弹窗中：
   - 选择安排房间（默认已锁定房间，可换同房型可用房）；
   - 确认入住人姓名；
   - 录入证件号（必填，至少 15 位，加密存储）；
   - 填写押金金额与方式（微信/支付宝/现金/银行卡）；
   - 填写房卡号（可留空自动生成）；
5. 点击「确认入住」。

完成后：

- 订单状态变为「在住」；
- 房间状态变为「在住」；
- 生成入住登记与押金记录；
- 生成公安报送记录（演示环境为模拟成功）；
- 写入站内消息与订单状态日志。

> 实名登记是强制要求；证件号无效会阻止入住。未成年人请在订单详情/入住信息中补充监护人信息。

### 2.2 预离订单

1. 查看「预离订单」；
2. 点击「退房结算」；
3. 核对/填写：
   - 优惠金额；
   - 其他费用（迷你吧、餐饮、赔偿等）；
   - 押金扣减（不能超过实收押金）；
   - 结算方式（微信/支付宝/现金/银行卡/协议挂账）；
   - 备注；
4. 点击「确认退房」。

完成后：

- 订单状态变为「已退房」；
- 生成结算单与收银流水；
- 押金余额自动退还并写押金流水；
- 房间状态变为「脏房」；
- 自动生成退房清扫任务；
- 会员订单自动累计积分/储值。

> 若金额不正确，先检查「房型/房间/房价」中的房价日历；系统按逐夜房价计算房费。

## 3. 入住登记与在住管理

### 3.1 查询入住记录

「入住登记」Tab：

- 按状态筛选（在住/已退房）；
- 按入住人姓名搜索；
- 查看证件号（掩码）、房间、房型、门店、入住时间、预计离店、押金、房卡、状态；
- 点击「变更记录」查看续住/换房/提前退/延时退历史。

### 3.2 续住

1. 进入「预订管理」；
2. 找到在住订单；
3. 点击「更多 → 续住」；
4. 选择新的离店日期；
5. 填写备注并确认。

系统会重新计算房费并更新订单；请确认新房态/房价无冲突。

### 3.3 换房

1. 进入「预订管理」；
2. 在住订单点击「更多 → 换房」；
3. 选择目标房间；
4. 确认。

系统会释放原房、占用新房，并写入在住变更记录与房态日志。

### 3.4 押金

1. 在住订单点击「更多 → 押金」；
2. 选择「收取」或「退还」；
3. 填写金额与支付方式；
4. 确认。

押金退还金额不能超过实收押金；所有操作可在「收银财务 → 押金流水」追溯。

### 3.5 取消订单

- 仅 `待确认/已确认/候补` 可取消；
- 「更多 → 取消订单」填写原因；
- 系统释放房间、写状态日志与站内消息。

## 4. 公安实名报送

「公安报送」Tab：

- 查看入住人、证件号（掩码）、房间、报送时间、状态、回执；
- 失败记录可点击「重新报送」；
- 当前为演示环境：报送成功为模拟回执；真实环境需配置公安旅馆业系统接口。

> 合规提醒：真实上线必须按当地公安要求完成旅客信息登记、未成年人报告、证件加密与日志脱敏。

---

## 5. 房态与客房协作

前台可在「房型/房间/房价」查看实时房态：

| 房态 | 含义 | 前台动作 |
|---|---|---|
| 空房 | 可售 | 可安排入住 |
| 预订 | 已锁定 | 等到店或改期/取消 |
| 在住 | 已入住 | 办理续住/换房/退房 |
| 脏房 | 待清扫 | 等待保洁置净，不可直接售卖 |
| 维修 | 维修中 | 联系维修，完成后改房态 |
| 关闭 | 停用 | 不可售卖 |

- 退房后房间自动变「脏房」，并生成清扫任务；
- 保洁完成后房间变「空房」；
- 前台可在房态页手动变更并填写备注，系统留痕。

---

## 6. 交班

1. 进入「收银财务 → 交接班」；
2. 开班时填写备用金；
3. 交班前核对：
   - 结算单/收银流水；
   - 押金收取/退还；
   - 挂账；
4. 点击「交班」，填写交班金额；
5. 下一班次重新开班。

> 同一门店已有未关闭班次时，不能重复开班。

## 7. 常见问题

**Q：预抵列表没有订单？**
A：检查订单入住日期是否为今天、状态是否为已确认/待确认；跨日订单不会出现在今日预抵。

**Q：办理入住时没有可选房间？**
A：房型已满、房间被关闭/维修或房态为脏房；先联系保洁置净或调整房型。

**Q：退房提示“订单未在住”？**
A：订单可能已退房或未办理入住；刷新列表确认状态。

**Q：押金扣减填多了？**
A：系统会拦截“押金抵扣不能超过实收押金”；请核对押金流水。

**Q：客人提前离店/延时离店怎么处理？**
A：当前通过退房结算的日期/费用调整实现；延时离店可先续住再退房，提前离店在结算中调整优惠/其他费用并备注。专用“提前退/延时退”按钮尚未提供，操作记录可在订单备注与审计中追溯。

**Q：换房后原房为什么还是脏房？**
A：换房释放的原房需保洁清扫；请创建/等待清扫任务后置净。

**Q：公安报送失败怎么办？**
A：点击「重新报送」；若持续失败，联系管理员检查接口配置（演示环境不会真实失败）。

## 8. 前台每日清单

- [ ] 开班：核对备用金、查看今日预抵/预离/脏房
- [ ] 到店：实名登记、收押金、发房卡、确认公安报送
- [ ] 在住：处理续住/换房/补押金/客诉
- [ ] 离店：结算、退押金、确认房间转脏、通知保洁
- [ ] 交班：核对现金/流水/押金/挂账，完成交接班
