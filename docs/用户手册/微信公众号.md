# 微信公众号（服务号）配置与运营手册

> 定位：微信公众号是“消息触达 + 预订引流”渠道，不是独立后台系统。
> 后台入口：PC 管理后台 →「系统配置」→「微信与通知」。
> 追溯：PRO.md §2.5 微信公众号（服务号）、§3.8 微信开放平台与消息配置；checklist §十八「公众号」。

---

| 能力 | 当前状态 | 落地方式 |

| 公众号模板消息真实发送 | **未实现** | 未调用微信“发送模板消息”接口 |
| 服务器 URL 回调（关注/取关/事件） | **未实现** | 无 `/wechat/callback` 验签与消息处理 |
| 自定义菜单后台编辑与一键同步 | **未实现** | 需在微信公众平台手工配置 |
| 图文素材/粉丝标签/定向群发 | **未实现** | 需在微信公众平台后台操作 |
| 网页授权 `snsapi_userinfo` / UnionID 互通 | **未实现** | 当前 H5/小程序为演示 OpenId |

## 2. 上线前资质与准备

由运营方/租户准备：

1. 已认证的微信服务号（订阅号不支持模板消息等能力）；
2. 微信开放平台账号，并将服务号与小程序绑定到同一开放平台主体（UnionID 前提）；
3. 公众号 AppID、AppSecret；
4. 服务器配置：URL、Token、EncodingAESKey（需公网 HTTPS、80/443 可达）；
5. 网页授权域名、JS 接口安全域名、业务域名（均需备案/校验）；
6. 模板消息模板 ID：预订确认、入住提醒、退房提醒、会员升级、优惠活动、审核结果等；
7. IP 白名单（如微信侧要求）；
8. 隐私政策、用户协议、个人信息收集清单。

> AppSecret、EncodingAESKey 属高敏凭据：只填后台，不入库明文、不截图、不发群。

## 3. 后台配置步骤

### 3.1 进入配置页

1. 使用租户管理员登录 `/admin/`；
2. 左侧「系统配置」；
3. 切到「微信与通知」Tab；
4. 在“微信公众号 / 小程序配置”表中选择应用类型为「公众号」的记录，点击「配置」。

### 3.2 填写公众号参数

| 字段 | 说明 |
|---|---|
| 应用类型 | 选择「公众号」（`OFFICIAL`） |
| AppId | 公众平台 → 设置与开发 → 基本配置 |
| AppSecret | 同上；保存后仅显示掩码，留空或含 `******` 表示不修改 |
| Token | 自定义，与微信服务器配置一致 |
| AES Key | EncodingAESKey，43 位；保存后掩码 |
| 业务域名 | 例如 `https://hotel.example.com` |
| 启用 | 关闭后该租户不认为公众号可用 |

保存后：

- AppSecret/AES Key 使用系统 `CryptoService` 加密入库；
- 列表只返回掩码（前 3 + `******` + 后 3）；
- 操作写入审计日志；
- 按 `tenant_id` 隔离，租户之间互不可见。

### 3.3 维护通知模板

“通知模板”表支持新增/编辑：

| 字段 | 示例 |
|---|---|
| 业务类型 | `BOOKING_CONFIRM`、`CHECKIN_REMIND`、`CHECKOUT_REMIND`、`MEMBER_UPGRADE`、`COUPON` |
| 渠道 | 站内 / 公众号 / 小程序 / 短信 |
| 模板 ID | 微信公众平台申请到的模板 ID（演示为 `TPL-*` 占位） |
| 标题 | 可含占位符，如 `预订确认：{{store}}/{{roomType}}/{{checkIn}}` |
| 内容 | 模板内容/变量说明 |
| 启用 | 是否启用该模板 |

> 模板 ID 只是“配置记录”。当前后端不会因保存模板 ID 就自动发公众号消息；真实发送需补发送服务与回调/授权链路。

### 3.4 查看站内消息

同页“站内消息”表展示最近消息：标题、内容、渠道、状态、时间。可用于核对预订/入住/退房事件是否产生通知。

## 4. 微信侧配置（外部平台操作）

以下操作在微信公众平台完成，不属于本系统后台：

### 4.1 服务器配置

1. 设置与开发 → 基本配置 → 服务器配置；
2. URL：计划由后端提供的回调地址，例如 `https://hotel.example.com/api/wechat/callback`；
3. Token：与后台配置一致；
4. EncodingAESKey：与后台一致；
5. 消息加解密方式：建议安全模式；
6. 提交时微信会发起校验请求。

> **当前后端尚未实现该回调接口**，直接填写会校验失败。需先完成回调验签/解密/事件处理开发，再启用。

### 4.2 网页授权域名

1. 设置与开发 → 公众号设置 → 功能设置；
2. 配置网页授权域名（H5 门户域名）；
3. 下载校验文件放到门户根目录，确保可访问；
4. 授权回调页使用 `https://hotel.example.com/` 下的页面。

> H5 当前为演示 OpenId 登录，未接 `snsapi_userinfo`；配置域名不会自动产生 UnionID 登录。

### 4.3 自定义菜单

当前无后台同步能力，需在公众平台手工配置：

| 菜单 | 类型 | 目标 |
|---|---|---|
| 立即预订 | 跳转网页 | `https://hotel.example.com/` |
| 房型房价 | 跳转网页 | `https://hotel.example.com/` 房型区 |
| 会员中心 | 跳转网页 | `https://hotel.example.com/member`（按实际路由） |
| 门店位置 | 跳转网页/文字 | 门店地址页或地图链接 |
| 联系客服 | 文字/客服 | 客服电话或客服会话 |

> H5 路由以 `portal-web/src/router` 为准；若使用 history 模式，Nginx 需 `try_files ... /index.html`（已提供）。

### 4.4 自动回复

公众平台 → 自动回复：

- 被关注回复：品牌介绍 + 预订入口链接；
- 关键词回复：`预订`、`房价`、`位置`、`会员`、`优惠`；
- 收到消息回复：引导至 H5/人工客服。

### 4.5 模板消息

1. 公众号后台 → 模板消息 → 从模板库选用/申请；
2. 记录模板 ID；
3. 填入本系统后台“通知模板”；
4. 真实发送还需：access_token 管理、OpenID 绑定、模板变量映射、失败重试、发送日志、频率控制。

> 以上发送链路当前**未实现**；后台只保存配置。

## 5. 会员与 UnionID 运营链路（目标态）

```text
用户关注公众号
  → 网页授权/扫码进入 H5
  → 后端用 code 换 openid/unionid
  → 绑定本租户会员档案（一人一档）
  → 小程序/App 同 UnionID 登录命中同一会员
  → 下单/入住/退房事件
  → 模板消息/订阅消息触达
```

当前实际链路：

```text
H5/小程序/App 演示 OpenId
  → /auth/wechat-login 创建/匹配会员
  → 返回本系统 JWT
  → 事件写站内消息
```

差距：真实 `code2Session`/网页授权、UnionID 绑定、模板消息发送、回调事件处理。

## 6. 安全与合规

- AppSecret/AES Key 加密存储，页面掩码；禁止在日志/截图/工单中暴露；
- 后台微信配置仅租户管理员可改，写审计；
- 模板消息必须用户授权/关注，禁止骚扰式群发；
- 群发受微信频率与配额限制，需限流与失败重试；
- 身份证号、手机号按敏感字段加密/脱敏；
- 公众号菜单/图文不得含虚假宣传、违规收集个人信息；
- 上线前完成隐私政策、用户协议、个人信息收集清单与撤回机制。

## 7. 常见问题

**Q：后台保存公众号配置后就能发模板消息吗？**
A：不能。当前只完成配置存储与掩码展示，发送接口/回调/授权未实现。

**Q：微信服务器配置 URL 提交失败？**
A：后端没有回调验签接口，或 Token/AES Key 不一致、URL 非 HTTPS/不可达。

**Q：后台改了菜单，公众号没变化？**
A：当前没有菜单同步能力；请在微信公众平台手工配置。

**Q：H5 在微信里打开能登录，但没有 UnionID？**
A：H5 是演示 OpenId 登录，未接网页授权；需补 `snsapi_userinfo` 与后端换 UnionID。

**Q：模板消息发送失败/收不到？**
A：检查模板 ID、OpenID、access_token、IP 白名单、频率限制；当前系统未实现真实发送，先完成联调。

**Q：多租户会不会串公众号？**
A：配置与模板均按 `tenant_id` 隔离；每个租户需绑定各自主体一致的公众号（UnionID 主体一致）。

**Q：能直接群发优惠活动吗？**
A：当前后台无群发功能；请在公众平台操作，或完成素材/粉丝/群发接口开发后再纳入验收。
