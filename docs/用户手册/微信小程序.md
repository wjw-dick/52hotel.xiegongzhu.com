# 微信小程序用户手册（C 端预订）

> 目录：`miniprogram/`；技术形态：微信原生小程序（WXML/WXSS/JS）。
> 面向：住客/会员；同时供运营人员完成开发版导入、接口地址配置与验收。
> 追溯：PRO.md §2.4 微信小程序；checklist §十八「小程序」、§五（预订/订单）、§九（会员）。

## 2. 开发前配置

### 2.1 修改接口地址

打开 `miniprogram/app.js`：

```js
const config = {
  // 真机调试必须改为开发机/服务器局域网 IP，不能写 127.0.0.1
  baseUrl: 'http://192.168.1.20:19090/api',
  tenantCode: 'YQ-HZ'
}
```

- 端口以实际后端为准：演示环境为 `19090`，生产为 `8080`；
- `tenantCode` 必须是已开通租户编码（演示：`YQ-HZ`、`XH-SH`）；
- 手机与开发机需在同一局域网，或使用内网穿透/已备案 HTTPS 域名。

### 2.2 导入微信开发者工具

1. 打开微信开发者工具 →「导入项目」；
2. 目录选择 `miniprogram/`；
3. AppID 可先用测试号（`project.config.json` 内为 `touristappid`），正式发布改为自有小程序 AppID；
4. 「详情 → 本地设置」勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”；
5. 编译，确认首页能加载房型与门店。

> 正式环境必须在微信公众平台配置 request 合法域名（HTTPS），并移除“不校验合法域名”。

### 2.3 后端准备

- 后端已启动：`curl http://<IP>:19090/api/health` 返回 `code=0`；
- 租户已初始化门店、房型、房间、房价；
- 小程序访问的是公网接口，无需后台账号；
- 若首页空白，先查 `GET /api/public/YQ-HZ/home` 是否返回数据。

## 3. 首页

进入小程序后默认「首页」：

1. 顶部品牌区：租户名称、宣传语；
2. 快速预订：选择入住/离店日期 →「查询房态并预订」；
3. 公告：租户配置的公告文案；
4. 房型甄选：封面、门店、房型名、面积、可住人数、床型、简介、起价；
5. 门店展示：名称、城市、地址、简介、电话；
6. 底部 tabBar：首页 / 预订 / 订单 / 我的。

操作提示：

- 入住日期不能早于今天；
- 离店日期自动晚于入住日期；
- 下拉可刷新首页数据。

---

## 4. 房型详情

点击房型卡片进入：

- 房型图片、名称、面积、可住人数、床型、设施、简介；
- 未来房价日历（日期 + 价格）；
- 选择入住/离店日期后实时查询可订房量；
- 显示晚数与参考总价；
- 「立即预订」携带房型与日期进入预订页。

> 房价为当前房价日历/门市参考价；节假日、渠道价以实际查询结果为准。

## 5. 在线预订

### 5.1 填写内容

| 字段 | 必填 | 说明 |
|---|---|---|
| 门店 | 是 | 切换门店后房型联动 |
| 房型 | 是 | 显示起价 |
| 入住/离店 | 是 | 离店晚于入住 |
| 房间数 | 是 | 1~3 间 |
| 姓名 | 是 | 真实姓名 |
| 手机号 | 是 | 11 位手机号，用于确认与查单 |
| 身份证号 | 是 | 至少 15 位，后端加密存储 |
| 协议单位 | 否 | 企业协议客户 |
| 备注 | 否 | 高楼层、安静、预计到店时间等 |

页面实时显示：可订房量、参考单价、预计总价（单价 × 晚数 × 间数）。

### 5.2 提交

1. 点击底部「提交预订」；
2. 系统校验必填项、手机号格式、证件长度、可订房量；
3. 成功后弹窗显示订单号，并自动跳转「订单」页；
4. 订单号与手机号会暂存，用于自动查询。

> 提交即锁定房间。当前仅支持“到店支付”；在线支付未接入微信支付，页面不展示支付跳转。

### 5.3 防重复提交

每次提交携带 `X-Request-Id`；后端对相同请求号做防重，重复提交返回限流/重复提示。

## 6. 订单

### 6.1 订单查询（免登录）

1. 进入「订单」；
2. 输入订单号与下单手机号；
3. 点击「查询订单」；
4. 查看订单号、门店、房型、状态、入住人、日期、房间、金额、备注。

手机号与订单不匹配会提示无权限，避免订单信息泄露。

### 6.2 我的订单（需登录）

登录后展示本人订单：

- 订单号、状态、入住/离店、晚数、金额；
- 待确认/已确认订单可「取消订单」；
- 取消前二次确认；取消后释放房间并刷新列表。

> 已入住/已退房/已取消订单不可在小程序自助取消，请联系门店。

## 7. 会员中心（我的）

### 7.1 演示登录

1. 进入「我的」；
2. 填写昵称、手机号（选填）；
3. 点击「微信一键登录」；
4. 系统以固定/随机 OpenId 调用 `/auth/wechat-login`，返回会员 JWT 并本地缓存。

> 这是演示占位，不是真实微信授权。正式上线需：
> - 小程序调用 `wx.login` 获取 code；
> - 后端 `code2Session` 换 openid/session_key；
> - 绑定开放平台后获取 UnionID；
> - 再签发本系统 token。

### 7.2 会员信息

- 昵称、手机号、会员等级；
- 可用积分、可用优惠券数量；
- 等级权益说明（由后台等级配置）。

### 7.3 积分 / 优惠券

- 积分：变动值、原因、时间；
- 优惠券：名称、面额、有效期；
- 均为只读，发放由后台/活动完成。

### 7.4 退出

点击「退出」清除本地 token 与会员资料。

## 8. 运营配置与发布

1. 后台「系统配置 → 微信配置」维护小程序 AppID/AppSecret（密文保存、回显掩码）；
2. 后台「租户配置」维护名称、Logo、客服电话、公告、门店/房型内容；
3. 正式发布前在微信公众平台完成：
   - 小程序类目与资质；
   - request 合法域名（HTTPS）；
   - 隐私保护指引与用户协议；
   - 订阅消息模板（如启用）；
4. 使用微信开发者工具「上传」→ 公众平台提交审核 → 发布。

> 小程序包内 `baseUrl` 是编译期常量；切换生产域名需改代码后重新上传，不能像 H5 一样只改 Nginx。

## 9. 常见问题

**Q：首页提示“网络异常，请检查 API 地址”？**
A：`baseUrl` 仍是 `127.0.0.1` 或端口不对；真机不能用回环地址，改为局域网 IP/域名并确认后端监听 `0.0.0.0`。

**Q：请求被微信拦截/提示域名不合法？**
A：开发阶段勾选“不校验合法域名”；正式环境在公众平台配置 HTTPS 合法域名。

**Q：查询不到房型？**
A：租户编码错误、门店/房型未启用、后端无数据，先用 `curl /api/public/{tenantCode}/home` 排查。

**Q：提交提示“暂无可订房”？**
A：日期已被订满或房间未配置；换日期/房型，或在后台检查房态与房价日历。

**Q：登录后看不到历史订单？**
A：演示登录以 OpenId 匹配会员，匿名下单不会自动归属；用订单号 + 手机号查询。

**Q：收不到预订通知？**
A：当前未接入订阅消息/模板消息；站内消息可在 H5/后台查看，真实推送需外部配置。

**Q：能否在小程序改密码？**
A：当前未提供；请使用 H5 会员中心或联系门店。后续可按 `/member/password` 接口补充页面。
